# Sistem Pakar Prioritas Tiket Layanan TI

## Deskripsi Proyek

Proyek ini merupakan tugas praktikum mata kuliah **Kecerdasan Buatan (Artificial Intelligence)** dengan bidang **Sistem Pakar (Expert System)**. Sistem dirancang untuk menentukan prioritas tiket layanan Helpdesk TI menggunakan metode **Forward Chaining** berdasarkan aturan IF–THEN.

## Fitur Sistem

* Menentukan prioritas tiket secara otomatis.
* Menggunakan metode Forward Chaining.
* Input berupa jenis gangguan, jumlah pengguna terdampak, urgensi, dan status layanan.
* Output berupa prioritas **KRITIS**, **TINGGI**, **SEDANG**, atau **RENDAH**.

## Teknologi yang Digunakan

* Python 3
* Google Colab
* GitHub

## Cara Menjalankan

1. Buka file `Sistem_Pakar_Prioritas_Tiket.ipynb`.
2. Jalankan seluruh cell dari atas ke bawah.
3. Masukkan data gangguan ketika diminta.
4. Sistem akan menampilkan hasil prioritas tiket.
